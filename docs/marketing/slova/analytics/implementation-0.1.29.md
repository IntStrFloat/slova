# Релиз 0.1.29 — аналитика и исправления игры

Дата: 2026-11-01. Приложение: com.intstrfloat.slova. Версия:0.1.29, versionCode33.

## Что реализовано

Внедрены изменения из аудита AppMetrica: плоская схема3 с миграцией2, типизированные контракты, версии контента/политики, анонимные SDK device/install identities, исключение QA и сохранённая граница согласия. Lifetime dedupe и durable queue защищают подтверждённые факты от повторов и вытеснения напоминаниями. Вариант эксперимента сохраняется при задержке и перезапуске.

Уровни получили pause/exit/checkpoint/blocked, активное время, сводки сохранений и корректную классификацию смысловой подсказки. Время периода отказа не отправляется после включения. Hard kill остаётся цензурированной попыткой; последние до5секунд могут не попасть в snapshot.

Экономика покрывается подтверждёнными транзакциями и ошибками выдачи. Колесо, daily, личная неделя, задания, коллекция и марафон используют доменные ключи/исходное время. Марафонный итог поддерживает correction revision после позднего восстановления. Для начального остатка добавлен wallet_balance_observed: всего38новых типов, включая37из драфта.

Добавлены экраны/значимые UI-действия, профиль, настройки, практика, push route и health summaries. Assignment/exposure готовы; активных экспериментов и нового расписания аналитика нет.

Рекламные события соответствуют реальным callback. Предзагрузка может быть раньше show eligibility. Автообновление баннера не предоставляет request ID — эти показы явно marked unknown. Рекламная выручка не дублируется ручной отправкой.

Подписка использует client management/entitlement и verified backend journal. Открытый браузер не создаёт продажу. Асинхронный binding не задерживает оплату; ранний платёж до подтверждения связи может остаться unlinked.

## Сервер

На живой сервер применены только analytics-hunks5файлов: index.cjs и runtime/billing{,-robokassa,-http,-analytics}.cjs. Изменения серверного кода вне этих hunks сохранены. Создана резервная копия, проверены syntax/require, выполнен один restart только slova-backend. Health и каталог оплаты не изменились; unauthorized analytics-binding отвечает401. Env и пользовательские данные сохранены.

**Необходимое внешнее условие:** отдельного AppMetrica Post API key на сервере нет. Endpoint/journal работают, отправка серверных финансовых событий выключена до ключа и APPMETRICA_SERVER_EVENTS_ENABLED=1. SDK key не подменяет Post key. Клиентская игровая аналитика использует существующий SDK.
