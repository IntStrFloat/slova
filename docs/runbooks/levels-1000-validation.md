# Проверка расширения до 1000 уровней

Дата: 2026-09-06. Изменения подготовлены в рабочей копии; публикация приложения и отправка пуша не выполнялись.

## Поведение

- Уровни 501–1000 продолжают путешествие по семи существующим городам. Использованы прежние изображения и отдельные идентификаторы карточек второго маршрута.
- Старые пакеты 1–500 сохраняются побайтно; их контрольные суммы закреплены в `assets/content/preserved-packs.json`. Игрок с сохранённым уровнем 501 получает продолжение без сброса прогресса. Награда за старый финал 500 остаётся 150 монет.
- В новых головоломках не больше восьми букв и сетка не больше 9×10. Диаметр колеса не опускается ниже 280 на проверенных ширинах от 320. Клетки кроссворда сохраняют минимум 24; при нехватке места прокручивается область над колесом.
- Четырёхзначный заголовок переносится при большом балансе монет. После получения последней награды открывается карта; последняя карточка сохраняется в коллекции.
- Кампания `levels-expanded-1000-v1` остаётся черновиком. Подробности и ограничения аудитории: [инструкция по пушу](levels-expanded-push.md).

## Проверки интерфейса

Playwright проверял реальное Expo web-превью с изолированными тестовыми сохранениями. Внешние `/api/` запросы перехватывались и получали тестовый ответ 503; такие сообщения в консоли не означают ошибку игрового интерфейса.

| Сценарий | Размер экрана | Диаметр колеса |
|---|---|---|
| Уровень 501 | 360×640 | 293 |
| Уровень 999 | 360×640 | 280 |
| Уровень 1000, баланс 123456 | 320×568 | 281 |
| Уровень 1000, баланс 123456 | 393×852 | 343 |
| Высокая сетка старого уровня 460 | 320×568 | 280 |

На всех этих экранах колесо помещается по ширине и высоте, заголовок целиком виден, область кроссворда заканчивается выше колеса. На уровне 460 прокрутка на 107 пикселей открыла нижнюю часть поля, сохранив размер и положение колеса.

Уровень 1000 пройден проводками указателя по буквам: «бордовый», «добро», «выбор», «обрыв», «боров», «роды». После нажатия «На карту путешествия» подтверждены `currentLevel = 1001`, 1000 пройденных уровней, баланс 200 → 400 и карточка `spb-palacebridge-route2`.

Скриншоты и воспроизводимые проверки находятся в `output/playwright/`: `verify-expanded-layout.cjs`, `verify-board-scroll.cjs`, `solve-finale.cjs`, `level1000-320x568.png`, `level1000-complete-360x640.png`, `home-claimed1000-360x640.png`. Итог visual-verdict — 95/100.

## Автоматические проверки

- Финальные пакеты после вычитки: строгий аудит прошёл без ошибок и предупреждений; 1000 уникальных пазлов, контрольные суммы всех семи прежних пакетов совпали. Отчёт: `assets/content/content-audit.json`.
- Полный Jest: 36 наборов, 144 теста прошли.
- После последней генерации повторены тесты контента, загрузчика, прогресса, наград и геометрии: ещё 25 проверок прошли. Матрица скриншотов также повторена на окончательных файлах.
- Backend и sender: 23 теста прошли, включая параллельный запуск и запрет повторной отправки после неоднозначного ответа.
- `npm run typecheck`, `npm run lint`, проверки синтаксиса изменённых CJS/JS и `git diff --check` прошли.
- Матрица всех уровней на четырёх ширинах проверяет минимальный размер колеса, клеток и отсутствие пересечения букв.

## Границы проверки

Подключённого Android-устройства не было. Native push проверен тестами адаптера и сигнатурами установленного SDK; реальная доставка требует проверки на Android с RuStore. Старые установки попадут в новую аудиторию только после открытия обновлённой версии с разрешёнными уведомлениями. Подготовленный sender не делает запросов без явного `--send`.
