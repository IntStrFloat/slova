# Архитектура

- Expo SDK 56 / RN 0.85; Android. Переиспользуем UI и кошелёк проекта.
- Новый отдельный marathon snapshot не изменяет released retention schema или старые eventInstances.
- Доказательство завершения берётся из durable retention maps. Settlement вызывается и при replay, чтобы восстановить промежуток между двумя записями.
- Награды пишутся в outbox до кошелька; кошелёк `addOnce` исключает повторную оплату. Startup/foreground повторяют reconciliation.
- Даты фиксированы в UTC+3; окно полуоткрытое. После завершения экран показывает сохранённый итог, новые результаты не учитываются.
- Deeplink `slova://marathon`; отдельный экран `/marathon`; вход Home без retention gate.
- Изменение backend не требуется; используем существующие события analytics без дополнительных данных.
- Дата устройства определяет локальное офлайн-окно, как у существующих daily/retention механик. Серверную защиту от изменения часов эта версия не обещает.
