# SDK и зависимости

Новых SDK/зависимостей для марафона не требуется. Используются существующие MMKV, Zustand, Expo Router, UI, кошелёк и analytics. RuStore event request является инструментом Консоли, не клиентским SDK. Текущие push/review/advertising интеграции не перенастраиваются в рамках этого события.
