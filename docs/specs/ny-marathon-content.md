# Новогодний марафон слов · 30 тематических кроссвордов

Расписание для сезона 2026/27. Каждое воскресенье в 00:00 МСК открываются пять открыток. Все открытые главы доступны до 1 февраля, 00:00 МСК. Последний игровой день — 31 января.

## Редакторская проверка

В первой версии колоды тематическое слово часто соседствовало со случайными анаграммами. Например, «фонарик» сопровождали «норка», «кран», «кино» и «риф». Из открытки с конфетой игроку приходилось извлекать «танк», из снежинки — «жена» и «сена». В новой колоде каждый обязательный ответ называет видимый предмет, действие или признак одной сцены. Последняя колонка даёт художнику проверяемую связь между ответами. Эту фразу показываем только после решения, чтобы она не раскрывала ответы заранее.

Для русскоязычной аудитории стран СНГ выбраны бытовые сцены со знакомой лексикой — ёлочный базар, бумажная почта, домашняя выпечка, дворовой хоккей, лесная кормушка, кукольный театр. Это художественный маршрут одной зимы. Для участия не требуется знать конкретную национальную традицию, религиозный праздник или местное название блюда. Универсальность восприятия предстоит проверить с игроками из разных стран.

Диск задан для сцены и может содержать буквы нескольких ответов. В одной попытке каждая позиция используется один раз. Между ответами диск снова доступен целиком. «Ё» передаётся буквой «Е» на диске и в клетках по правилам игры, литературное написание сохранено в тексте. Для каждой открытки подготовлены две или три обязательные цели. Другие допустимые слова могут засчитываться по обычным правилам бонусов. Названия сцен служат подсказками, обязательные слова на старте скрыты.
